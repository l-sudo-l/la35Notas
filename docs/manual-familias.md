# Guía para Padres, Madres y Tutores

**No necesitan usuario ni contraseña.** El colegio les envía la información por correo electrónico.

## Qué van a recibir

- **Boletín de calificaciones** de cada período: notas por materia, promedios, asistencia y, si corresponde, contenidos pendientes. Llega **dentro del mismo mail**, listo para leer, imprimir o guardar como PDF.
- **Comunicados institucionales**: reuniones, avisos, cambios de horario, etc.

Los mails llegan con el asunto `[nombre del colegio] ...` desde la casilla oficial del colegio.

## Si no les llega

1. Revisen la carpeta de **spam o correo no deseado**. En el primer envío es habitual que caiga ahí: márquenlo como *No es spam* y agreguen la dirección a sus contactos.
2. Verifiquen que el colegio tenga **su mail correcto**. Si cambió, avisen a preceptoría.
3. Si siguen sin recibirlo, comuníquense con **preceptoría**: puede revisar si el envío salió y si el mail cargado es el correcto.

## Si ven un dato que no es correcto

Si una nota, una falta o un dato del alumno parece incorrecto, escriban o consulten a **preceptoría**. Solo el personal del colegio puede corregirlo.

## Guardar el boletín como PDF

Abran el mail → **Imprimir** → elijan **Guardar como PDF** como impresora.
